# Human-Tone Writing · 人味儿写作

> 让 AI 写出的文字**先写对、再写得不像 AI、最后写得有人味**。

一个用于 Claude Code 的写作 skill。适用于汇报、方案、述职、邮件、公众号、内部沟通稿、观点输出等一切「给人读、且要读起来像人写的」写作任务。

---

## 核心理念

人味儿写作分三步，层层递进：

```
写对 → 去味 → 增量
```

| 层 | 目标 | 内容 |
|----|------|------|
| **第 1 层 · 正向结构** | 先写对 | 读者视角、5W、金字塔结构（SCQA / 纵向 / 横向）、MECE、MBTI 匹配 |
| **第 2 层 · 去 AI 味** | 写得不像 AI | 有立场、细节代判断、感受代标签、意义膨胀清除、留白、节奏变化 |
| **第 3 层 · 人味儿增量** | 写得有人味 | 三诉诸（Ethos/Pathos/Logos）× 三风格 × 四类修辞格 |

---

## 为什么是「人味儿」

AI 写作的根源问题不在词汇，而在**思维层次**：

- AI 默认**中立**，人带**立场**
- AI 倾向**抽象**，人写**细节**
- AI 害怕犯错，倾向**可预测**，人敢于**出其不意**

所以去 AI 味不是换词，是换思路；加人味不是套修辞格，是找回「一个真实的人在说话」的感觉。

---

## 边界声明（本 skill 最诚实的部分）

> 人味儿不是清单。一旦写成 checklist，它就死了。

前两层是「技」，可以是清单；第三层是「道」，只能示范，不能执行。

第三层的终点不是「完成多少条目」，而是退后一步问自己：**这像不像一个活人在对我说话？**

## 安装

### 方式一：npx skills add

```bash
npx skills add <本仓库地址>
```

### 方式二：手动安装

```bash
# 克隆仓库
git clone <本仓库地址> ~/.claude/skills/人味儿写作
```

安装后，在 Claude Code 中：
- 直接描述写作需求（如「帮我写一段有温度的话」）自动触发
- 或新建斜杠命令 `/人味儿写作` 手动调用
