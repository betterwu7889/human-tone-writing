# Human-Tone Writing · 人味儿写作

> 换词解决不了 AI 味。把"赋能"换成"助力"，把"值得注意的是"删掉——换完词，文字还是 AI 味。
>
> 因为 AI 味的根源不在词，在**思维**——AI 没有立场、害怕犯错、倾向抽象、永远选最可预测的表达。
>
> 这个 skill 解决的是根源。

---

## 它能做什么

让人工智能写出的文字，走完三步：

```
写对 → 去味 → 增量
```

| 层 | 解决什么 | 一句话 |
|----|---------|--------|
| **写对** | 结构对不对 | 读者视角 + 金字塔结构 + MBTI 匹配 |
| **去味** | 像不像 AI | 改思维，不换词：有立场、写细节、留白 |
| **增量** | 有没有人味 | 三诉诸 × 三风格 × 四类修辞格 |

三步是递进的：先有正确的骨架，再洗掉机器腔，最后找回"一个真实的人在说话"的感觉。跳层就是半成品。

---

## 它和"换词"的思路，有什么不同

这个 skill 不给负面清单，而是给一套思考方式——改的是写作时**怎么想**，不是**用什么词**。

举例，同样一句"该员工具有较强的责任心"：

- 换词的做法：把"具有"换成"拥有"。
- 这个 skill 的做法：问一句"责任心长什么样"——改成"他为了等一个上游确认，在工位守到了凌晨"。

前者是改表面，后者是换角度。

---

## 最诚实的部分：它承认自己的边界

几乎所有 AI 写作工具都会假装"我能让你写出人味"。

这个 skill 不装。它明说：

> 人味儿不是清单。一旦写成 checklist，它就死了。

所以前两层（结构、去味）是可以执行的规则，第三层（人味）是示范、是道，不是条目。写到第三层，它会让 AI 停下来问自己：

**这像不像一个活人在对我说话？**

审视不出来，就直说"这段我写不出人味，需要你来品"——而不是硬凑一个答案。

这条诚实，比任何修辞格都更接近真实的人。也是这个 skill 区别于所有同类的根本。

```bash
# 方式一：skills 工具安装
npx skills add https://github.com/betterwu7889/human-tone-writing

# 方式二：手动安装
```

安装后，直接描述需求即可触发（"帮我写一段有温度的话"、"这稿子 AI 味太重帮我改改"）。也可建斜杠命令 `/人味儿写作` 手动调用。

## 适用与不适用

**适合**：汇报、方案、述职、邮件、公众号、观点输出——一切"给人读、且要读起来像人写的"。

**不适合**：技术文档、代码注释、机器对机器的输出。那些场景，"人味"是干扰项。
