# 修辞格与诉诸示例库

> 本文件是**示范**，不是清单。用法：写正文时按需翻阅，找感觉，不要机械套用。

---

## 一、四类修辞格的具体例句

### 1. 形象化类（把抽象变画面）

**明喻 / 暗喻**（"像" / "是"）
- 抽象写法：这个方案能显著提升效率。
- 人味写法：这个方案像把生锈的传送带重新上了油，之前卡半个月的流程，现在三天走完。

**类比**（关系层面的映射，不是词）
- 抽象写法：组织架构调整需要循序渐进。
- 人味写法：调架构就像换家具，你不能一次性把承重墙砸了，得先看哪面墙真在受力。

**通感**（感官互换）
- 抽象写法：这段数据很令人担忧。
- 人味写法：这组数字看着就硌牙，越往下读越坐不住。

**借代**（部分代整体）
- 抽象写法：需要高管层做出决策。
- 人味写法：这件事，得等三楼那张桌子拍板。

### 2. 强化类（制造力度，克制用）

**设问 / 反问**
- 抽象写法：我们需要重新审视这个问题。
- 人味写法：这个问题，我们真的想清楚了吗？还是只是绕着它走了一年？

**夸张**（点到即止）
- 抽象写法：这个工作量很大。
- 人味写法：这活儿多到能把一个团队埋进去。

### 3. 对比类（制造张力）

**对比 / 对偶**
- 抽象写法：我们需要在投入和产出之间平衡。
- 人味写法：少花的是现在，多付的是将来。

**反语**
- 抽象写法：这个进度并不理想。
- 人味写法：进度相当"稳健"——稳到三个月只前进了三天。

### 4. 意外类（打破预期，去味杀手锏）

**突降**（从高到低的反差）
- 平铺写法：这个项目最终失败了。
- 人味写法：我们开了十二次会、写了四份方案、做了两轮对齐——然后发现，问题出在一个没人问过的字段名上。

**悬念 / 延迟**
- 平铺写法：结果是坏的。
- 人味写法：先说结论——这个季度我们没达标。至于为什么，和你想的不太一样。

## 二、三诉诸的落地方式

**Ethos（人格）**：不是自夸"我很专业"，而是**展示分寸感**——该说的说透，不该说的留白，敢承认自己不知道。

**Pathos（情感）**：不是煽情，是**给一个具体的人的具体处境**。不要说"我们要关怀用户"，写"有个用户在凌晨两点留言说，他找了三天没找到入口"。

**Logos（逻辑）**：不是堆数据，是**让数据自己说话**——读者看到数字能直接得出结论，不需要再算一遍。

## 三、改稿对照（原句 → 改后）

| 原句（AI 味） | 改后（人味） |
|--------------|-------------|
| 值得一提的是，本次项目取得了显著成效 | 这项目，成了 |
| 我们需要高度重视这一问题 | 这个问题再拖，下季度就得买单 |
| 综上所述，该方案具有可行性 | 所以，干不干？ |
| 通过多措并举，实现降本增效 | 砍掉了两个中间环节，一个季度省下四十万 |
| 该员工具有较强的责任心 | 他为了等一个上游的确认，在工位守到了凌晨 |
